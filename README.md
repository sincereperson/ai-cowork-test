# ai-cowork-test

AI cowork 기능 테스트를 위한 저장소입니다.

## 목적

- AI cowork 에이전트와의 협업 워크플로우 검증
- 저장소 생성, 이슈 등록, PR 생성 등 기본 기능 테스트
- 에이전트 간 커뮤니케이션 및 작업 분배 테스트

## 테스트 항목

### 1. 저장소 관리
- [ ] 저장소 생성 및 설정
- [ ] README 작성
- [ ] 파일 추가/수정/삭제
- [ ] 브랜치 관리

### 2. 이슈 관리
- [ ] 이슈 생성 (버그/작업 분류)
- [ ] 이슈 상태 확인 및 조회
- [ ] 이슈 할당 및 라벨링
- [ ] 이슈 닫기

### 3. PR 관리
- [ ] PR 생성 (채널 연결 포함)
- [ ] PR 상태 확인
- [ ] 파일 변경 내역 확인

### 4. 에이전트 협업
- [ ] 이슈 기반 작업 할당
- [ ] 작업 진행 상황 보고
- [ ] 결과물 공유 및 리뷰

## 사용법

```bash
# 저장소 클론
git clone https://github.com/sincereperson/ai-cowork-test.git
cd ai-cowork-test

# 브랜치 생성
git checkout -b feature/test-branch

# 작업 후 커밋 및 푸시
git add .
git commit -m "feat: 테스트 내용"
git push origin feature/test-branch
```
